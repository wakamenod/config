macOS のキーリマップ（[[https://karabiner-elements.pqrs.org/][Karabiner-Elements]]）の設定。
tangle 先は =~/.config/karabiner/karabiner.json=。

* 注意: tangle は一方通行ではない

Karabiner-Elements は **GUI から設定を変更すると自分で karabiner.json を書き戻す**。
このファイルから tangle すると、GUI 側で加えた変更は消える。
逆に GUI を触った後にここから tangle すると、GUI の変更が失われる。

運用としてはどちらかに寄せる:

- ここを正とする（推奨）。GUI では設定せず、変更はこのファイルを編集して tangle し直す
- GUI を正とする。その場合このファイルは記録用と割り切り、GUI で変更したら
  =~/.config/karabiner/karabiner.json= の内容をここへ写し直す

tangle 前のバックアップは Karabiner 自身が =~/.config/karabiner/automatic_backups/= に
日付つきで残している。

* 全体の構造

プロファイルは 2 つ。=US= が有効で、=JIS= は使っていない予備。
ルール本体は両プロファイルで共有するので、noweb 参照で組み立てる。

#+NAME: karabiner-json
#+BEGIN_SRC json :tangle ~/.config/karabiner/karabiner.json :noweb yes
{
  "profiles": [
    <<profile-us>>,
    <<profile-jis>>
  ]
}
#+END_SRC

* ルール

各ルールは両プロファイルから参照される。=Spotlight を開くときに IME を英数にする= と
=F8 to Ctrl+Option+Shift+z= の 2 つのみ =US= 専用。

** esc に英数キーを重ねる（vim 用）

esc を押すと esc と英数を続けて送る。vim で挿入モードを抜けるときに
IME が日本語入力のままになるのを防ぐ。

#+NAME: rule-esc-eisuu
#+BEGIN_SRC json
{
  "description": "escキーを押したときに、英数キーも送信する（vim用）",
  "manipulators": [
    {
      "from": {
        "key_code": "escape"
      },
      "to": [
        {
          "key_code": "escape"
        },
        {
          "key_code": "japanese_eisuu"
        }
      ],
      "type": "basic"
    }
  ]
}
#+END_SRC

** Caps Lock をリバースキーにする

修飾キーと一緒に押すと **押していない側の修飾キー** が出る。

| 押すもの                     | 出るもの                  |
|------------------------------+---------------------------|
| Caps 単独                    | Cmd + Ctrl + Opt + Shift  |
| Shift + Caps                 | Opt + Ctrl + Cmd          |
| Cmd + Caps                   | Ctrl + Opt + Shift        |
| Cmd + Opt + Ctrl + Caps      | Shift                     |

修飾キーの組み合わせを片手で作るための仕掛けで、3 つ以上の同時押しを

** 英数・かなキーを Control と兼用する

単独で押せば従来どおり英数／かな、他のキーと同時に押すと Control になる。
英数が左 Control、かなが右 Control。

#+NAME: rule-eisuu-kana-control
#+BEGIN_SRC json
{
  "description": "英数・かなキーを他のキーと同時に押したときに、Controlキーを送信する",
  "manipulators": [
    {
      "from": {
        "key_code": "japanese_eisuu",
        "modifiers": {
          "optional": [
            "any"
          ]
        }
      },
      "parameters": {
        "basic.to_if_alone_timeout_milliseconds": 200
      },
      "to": [
        {
          "key_code": "left_control"
        }
      ],
      "to_if_alone": [
        {
          "key_code": "japanese_eisuu"
        }
      ],
      "type": "basic"
    },
    {
      "from": {
        "key_code": "japanese_kana",
        "modifiers": {
          "optional": [
            "any"
          ]
        }
      },
      "parameters": {
        "basic.to_if_alone_timeout_milliseconds": 200
      },
      "to": [
        {
          "key_code": "right_control"
        }
      ],
      "to_if_alone": [
        {
          "key_code": "japanese_kana"
        }
      ],
      "type": "basic"
    }
  ]
}
#+END_SRC

** Spotlight を開くときに IME を英数にする

Spotlight（と Alfred）のホットキーは Hyper + Space。Caps Lock のリバースキーと
組み合わせると実際の操作は Caps + Space になる。

押されたときに英数キーを先に送ってから本来の Hyper + Space を送るので、
検索窓が開いた時点で IME は必ず英語になっている。日本語入力のまま
アプリ名を打ち始めて変換候補が出る、という事故が無くなる。

英数を「先に」送るのが要点。順序を逆にすると、検索窓が開いた後に
IME が切り替わるので最初の 1 文字を取りこぼすことがある。

#+NAME: rule-spotlight-eisuu
#+BEGIN_SRC json
{
  "description": "Spotlight を開くときに IME を英数にする",
  "manipulators": [
    {
      "type": "basic",
      "from": {
        "key_code": "spacebar",
        "modifiers": {
          "mandatory": [
            "command",
            "control",
            "option",
            "shift"
          ],
          "optional": [
            "caps_lock"
          ]
        }
      },
      "to": [
        {
          "key_code": "japanese_eisuu"
        },
        {
          "key_code": "spacebar",
          "modifiers": [
            "left_command",
            "left_control",
            "left_option",
            "left_shift"
          ]
        }
      ]
    }
  ]
}
#+END_SRC
